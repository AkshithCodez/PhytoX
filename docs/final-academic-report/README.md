# PhytoX mini project report

The editable Word report and its 51-page print preview are in `deliverables/`. The cover, certificate and declaration use the supplied institutional file. Figures have editable SVG originals alongside their PNG exports. Chapter 5 follows the live demo from a dataset leaf scan through plot monitoring and officer reporting.

The verification folder records test results, known discrepancies and the three outputs from the local crop-conditioning example. The contents, figure list and table list contain editable page numbers. Recheck them after edits that change pagination.
